# MCR flower atlas

Saved asset: `public/mahjong/flowers-generated-v1.png`.
Generated using the built-in image generation tool, not CLI. Original preserved in Codex generated images. Visually inspected: 4 columns by 2 rows; top row 梅、兰、竹、菊; bottom row 春、夏、秋、冬. Shared MahjongTile uses this order and retains live Chinese/English labels; unknown tiles no longer receive an invalid negative sprite position.

Consumed in MCR practice and the MCR written lesson. No backend or runtime image service. Browser/layout acceptance remains pending.

## Final generation prompt

Use case: stylized-concept. Asset type: ONE game texture atlas for a realistic parchment RPG Mahjong teaching app. Generate a precise 4-column by 2-row sprite sheet of EIGHT distinct traditional Chinese Mahjong bonus tile faces. Canvas landscape 4:3, each equal grid cell is a vertical 2:3 portrait rectangle. Each cell contains one identical front-facing ivory ceramic tile filling its cell, clean dark green thin bevel, no perspective, crisp painted botanical art readable when small, uniform warm neutral lighting. Top row left to right: plum blossom branch (pink flowers), orchid (purple blossoms and long leaves), bamboo (green segmented stems and leaves), chrysanthemum (golden many-petaled flowers). Bottom row left to right: spring (fresh green shoots with blossoms), summer (pink lotus and broad green leaves), autumn (orange maple leaves), winter (snow-covered pine). Include the single Chinese character near upper left of each tile respectively: 梅 兰 竹 菊 / 春 夏 秋 冬. No extra text or numbers. Exact regular grid boundaries, no gaps between cells, no scene, no hands, no watermark. Detailed hand-painted illustration on realistic ivory, sharp outlines and clear differences, not emojis or abstract symbols. This is one tightly aligned tile atlas, not a UI screenshot.
