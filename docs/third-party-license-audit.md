GPLv3 section 6(d) covers network distribution of object code and requires equivalent access to its *Corresponding Source* and clear directions if source is on another server. The [GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#AnonFTPAndSendSources) emphasizes that the source must correspond to the exact binary version; the [Fairy-Stockfish project README](https://github.com/fairy-stockfish/Fairy-Stockfish/blob/master/README.md) similarly says to include source or a pointer capable of generating the exact binary. What the GPL requires of the **surrounding application** when using these browser-side modules is a separate legal question; this audit does not assume the entire app is or is not a derivative work.
